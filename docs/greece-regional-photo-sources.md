# Fotografías de las tres incorporaciones a Grecia

Revisión documental y visual de las miniaturas: 3 de noviembre de 2026. Este archivo cubre exclusivamente Preveza (PVK), Samos (SMI) y Kalamata (KLX), las tres incorporaciones al bloque seleccionado de quince aeropuertos internacionales. No modifica las fotografías de las doce fichas anteriores.

Los metadatos utilizados se conservan en `lib/destinations/greece-regional-images.ts`. Las URL de miniatura se observaron en los enlaces de resolución de las páginas de Commons: no se han deducido ni inventado los directorios de sus archivos.

## Estado de comprobación y límites

- Se consultaron las páginas de archivo y sus declaraciones de autor, dimensiones y licencia.
- Las tres miniaturas de 960 px cargaron en el navegador y se inspeccionaron sus píxeles: puerto de Préveza, puerto de Pythagoreio y casco antiguo de Calamata.
- La foto de Préveza conserva un pequeño crédito visible del fotógrafo; no se elimina ni se modifica el original.
- Esta comprobación directa acredita la carga de las imágenes; el recorte dentro de la ficha se comprueba adicionalmente en Preview.
- La cabecera compartida utiliza `object-cover`: Preveza y Samos son panorámicas amplias y deben revisarse en escritorio y móvil para confirmar que el recorte mantiene el puerto reconocible. Las dimensiones de 960 px son las miniaturas preparadas, no las originales.
- La presentación puede recortar las fotografías; se conservan fuente, autor y enlace de licencia. No se altera el original.

La investigación preliminar sobre los otros destinos regionales se ha dejado fuera de `work/greece` y no forma parte de esta ampliación. No se publica ni se modifica Production con estos archivos.
